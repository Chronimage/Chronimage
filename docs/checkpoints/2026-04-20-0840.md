## Notes

- `image_hasher` v2 has no `HashAlg::PHash` variant — pHash is achieved via `HashAlg::Median + .preproc_dct()`; this is documented in the crate but easy to miss
- `image-hasher` (hyphen) in Cargo.toml causes "no matching package" error — must be `image_hasher` (underscore)
- Clippy `field_reassign_with_default` fires when you do `let mut d = ExifData::default(); d.field = ...;` — refactor to struct literal
- Stage 4 AI runs *synchronously* at the end of `execute_pipeline` (not as a background task); if models are present, import will take longer per photo; consider making it a detached spawn if latency matters
- All 13 pipeline tests still pass after Stage 4 addition (AI skipped in tests — no model files in CI)
- reqwest 0.12 was already in the lockfile via tauri plugins; adding it explicitly caused no version conflicts
